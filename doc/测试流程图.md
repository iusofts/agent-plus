# Agent Plus 测试流程图

本文档包含用于测试 Agent Plus 工作流引擎的流程图设计。

---

## 1. 简单问答流程

```mermaid
graph TD
    A[Start<br/>节点 ID: start] -->|question| B[LLM<br/>节点 ID: llm<br/>模型: qwen-plus]
    B -->|answer| C[End<br/>节点 ID: end]

    style A fill:#90EE90
    style B fill:#87CEEB
    style C fill:#FFA07A
```

**工作流 JSON 示例：**

```json
{
  "id": "simple-chat",
  "name": "简单问答",
  "nodes": [
    {
      "id": "start",
      "type": "start",
      "data": {
        "inputParams": [
          {"name": "question", "label": "用户问题", "type": "string"}
        ]
      }
    },
    {
      "id": "llm",
      "type": "llm",
      "data": {
        "model": "qwen-plus",
        "systemPrompt": "你是一个乐于助人的AI助手。",
        "userPrompt": "{{question}}",
        "temperature": 0.7,
        "outputParams": [
          {"name": "answer", "label": "回答", "type": "string"}
        ]
      }
    },
    {
      "id": "end",
      "type": "end",
      "data": {
        "outputParams": [
          {"name": "result", "label": "最终结果", "value": "{{llm.answer}}"}
        ]
      }
    }
  ],
  "edges": [
    {"id": "e1", "source": "start", "target": "llm"},
    {"id": "e2", "source": "llm", "target": "end"}
  ]
}
```

## 3. 条件分支流程

```mermaid
graph TD
    A[Start<br/>节点 ID: start] -->|question| B[LLM<br/>节点 ID: analyze<br/>分析意图]
    B -->|intent| C{Condition<br/>节点 ID: condition}
    C -->|intent == 'greeting'| D[LLM<br/>节点 ID: greet<br/>问候回复]
    C -->|intent == 'question'| E[LLM<br/>节点 ID: answer<br/>问题回答]
    C -->|default| F[LLM<br/>节点 ID: default<br/>默认回复]
    D --> G[End]
    E --> G
    F --> G

    style A fill:#90EE90
    style B fill:#87CEEB
    style C fill:#FFD700
    style D fill:#98FB98
    style E fill:#98FB98
    style F fill:#98FB98
    style G fill:#FFA07A
```

**工作流 JSON 示例：**

```json
{
  "id": "conditional-flow",
  "name": "条件分支流程",
  "nodes": [
    {
      "id": "start",
      "type": "start",
      "data": {
        "inputParams": [
          {"name": "question", "label": "用户输入", "type": "string"}

      }
    },
    {
      "id": "analyze",

        "model": "qwen-plus",

    },

      "id": "condition",
      "type": "condition",

        "conditions": [
          {"field": "analyze.intent", "operator": "equals", "value": "greeting", "target": "greet"},

      "id": "greet",
      "type": "llm",
      "data": {
        "model": "qwen-plus",

        "model": "qwen-plus",

      }
    },
    {
      "id": "default",
      "type": "llm",

        "model": "qwen-plus",

      }

    {"id": "e1", "source": "start", "target": "analyze"},
    {"id": "e2", "source": "analyze", "target": "condition"},
    {"id": "e3", "source": "condition", "target": "greet", "condition": "greeting"},
    {"id": "e4", "source": "condition", "target": "answer", "condition": "question"},
    {"id": "e5", "source": "condition", "target": "default", "condition": "default"},
    {"id": "e6", "source": "greet", "target": "end"},
```

## 4. 批处理流程

```mermaid
graph TD
    A[Start<br/>节点 ID: start] -->|items| B[Batch<br/>节点 ID: batch<br/>批处理]
    subgraph Subgraph
        C[LLM<br/>处理单个项目]
    end
    B -->|item| C
    C -->|result| B
    B -->|results| D[Aggregator<br/>节点 ID: agg<br/>合并结果]
    D -->|summary| E[End]

    style A fill:#90EE90
    style B fill:#FF6347
    style C fill:#87CEEB
    style D fill:#9370DB
    style E fill:#FFA07A
```

**工作流 JSON 示例：**

```json
{
  "id": "batch-flow",
  "name": "批处理流程",
  "nodes": [
    {
      "id": "start",
      "type": "start",
      "data": {
        "inputParams": [
          {"name": "items", "label": "项目列表", "type": "array"}
        ]
      }
    },
    {
      "id": "batch",
      "type": "batch",
      "data": {
        "inputParam": "items",
        "itemParam": "item",
        "outputParam": "processedItems",
        "subgraph": {
          "nodes": [
            {
              "id": "sub-llm",
              "type": "llm",
              "data": {
                "model": "qwen-plus",
                "userPrompt": "处理这个项目：{{item}}",
                "outputParams": [{"name": "processed", "type": "string"}]
              }
            }
          ],
          "edges": []
        }
      }
    },
    {
      "id": "agg",
      "type": "aggregator",
      "data": {
        "inputParam": "batch.processedItems",
        "outputParam": "summary",
        "aggregation": "join"
      }
    },
    {
      "id": "end",
      "type": "end",
      "data": {
        "outputParams": [
          {"name": "result", "value": "{{agg.summary}}"}
        ]
      }
    }
  ],
  "edges": [
    {"id": "e1", "source": "start", "target": "batch"},
    {"id": "e2", "source": "batch", "target": "agg"},
    {"id": "e3", "source": "agg", "target": "end"}
  ]
}
```

## 5. 完整复杂流程

```mermaid
graph TD
    A[Start] --> B[LLM<br/>分析意图]
    B --> C{Condition}
    C -->|需要知识库| D[Knowledge<br/>检索]
    C -->|不需要| E[LLM<br/>直接回答]
    D --> F[LLM<br/>基于上下文回答]
    E --> G{需要列表?}
    F --> G
    G -->|是| H[Batch<br/>批处理]
    G -->|否| I[End]
    H --> J[Aggregator]
    J --> I

    style A fill:#90EE90
    style B fill:#87CEEB
    style C fill:#FFD700
    style D fill:#DDA0DD
    style E fill:#87CEEB
    style F fill:#87CEEB
    style G fill:#FFD700
    style H fill:#FF6347
    style J fill:#9370DB
    style I fill:#FFA07A
```

这个流程结合了：
- 意图分析
- 条件分支
- 知识库检索
- 批处理
- 结果聚合

## 快速测试

使用 `WorkflowQuickTest` 类进行快速测试：

```bash
cd agent-plus-engine
export DASHSCOPE_API_KEY=your-api-key
mvn test -Dtest=WorkflowQuickTest
```

或者直接运行主应用：

```bash
cd agent-plus-web
mvn spring-boot:run -Dspring-boot.run.profiles=dev
```

然后访问 Swagger UI: http://localhost:8080/swagger-ui.html
